# 用户管理移动端

- 1024px 及以下使用用户卡片，桌面继续使用详细表格；无需横向滚动到角色列。
- 卡片直接显示角色名称及原始 role 值，提供权限管理和重置密码入口。
- 长账号、邮箱和角色换行；触控按钮最小高度 44px，小屏下操作按钮可独占一行。
- 移动分页使用上一页/下一页，不挤压整页内容。
- 角色面板宽高受视口限制，中间内容独立滚动，顶部关闭和底部完成按钮不被挤出。
- 使用原生 checkbox 与整行 label，角色说明在名称下方显示，支持触控及键盘。
- 保留原角色 API，但授予/移除任意角色前先使用 FV `$infoBox` 二次确认，确认后才保存。
- 确认框显示目标账号、角色及授予/移除方向；管理员权限变更额外提示影响和撤销自身权限的风险。
- 取消确认不调用 API、不改变已保存权限或勾选状态；等待确认及保存期间禁止重复操作与关闭面板。
- 确认期间账号、角色或面板状态发生变化时，不提交过期操作。确认组件异常时不提交。
- 确认框适配窄屏，长账号换行、内容可滚动、操作按钮最小高度 44px。
- 服务端返回空角色字符串时正确清空显示；请求失败恢复选中状态并显示错误。
- 角色列表加载失败可重试；晚返回的请求不覆盖另一账号或较新的用户列表。
- 不改变后台鉴权、权限规则或数据库；验收不修改真实用户角色。

```sh
npm --prefix ui test
npm --prefix ui run build
```

自动化测试覆盖布局规则、模板编译、角色授予/撤销、最后角色清空、
确认及取消、过期确认、组件异常、失败回退、并发保护、账号切换、加载重试及分页边界。
二次确认是前端误触保护，不改变后端管理员鉴权，也不代替服务端权限校验。
代码和 HTTP 检查不等同于 iPhone 真机视觉/触控验收。
