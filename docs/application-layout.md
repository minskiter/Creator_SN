# 应用管理布局

应用管理沿用项目管理的页面布局，而非独立的卡片墙：

- 相同的页面边距、标题字号、底色、工具栏与纵向列表间距。
- 使用 vfluent3 搜索框、按钮和居中面板；编辑面板独立为 `ApplicationEditorPanel.vue`。
- 应用名称和状态、客户端类型、Client ID、回调地址分区展示。
- 网格使用 `minmax(0, 1fr)` 与长文本换行，窄屏时操作按钮和回调地址独立成行。
- 编辑保持原生表单校验；保存中禁止重复提交和关闭。
- Client Secret 仍只展示一次，确认保存后清空，不新增浏览器持久存储。
- 不变更 API、应用权限、已有客户端、回调地址或签名密钥。

验证：

```sh
npm --prefix ui test
npm --prefix ui run build
```

测试覆盖 SFC 编译、与项目管理的样式约束对比、长内容/窄屏规则、搜索、
创建/编辑提交、错误状态、并发保护、密钥关闭清空和表单校验调用。
这些检查不等同于真实浏览器视觉验收。
