# 应用弹窗与简历管理移动端修复

## 应用新增、编辑无响应

FV Panel 的 `thisValue` 在打开后会发送 `update:modelValue(true)`。应用编辑组件原先把所有更新事件绑定到 `close()`，于是打开后立即被关闭。

- 使用 `setVisible(value)` 转发真实状态，不再将打开事件当作关闭。
- 编辑及单次密钥面板通过 Vue Teleport 挂载到 body，避免被后台滚动容器裁切。
- 表单独立滚动、头尾不收缩；缺失表单引用时安全返回，不抛出空引用错误。
- 原有校验、创建/更新 API、仅展示一次密钥和保存期间的操作限制保留。

## 简历管理

- 1024px 及以下显示卡片，完整展示成员、绑定账户、邮箱、更新时间及编辑/删除入口。
- 长账户与邮箱换行，触控按钮最小高度 44px；窄屏标题及字段纵向排列。
- 简历编辑面板挂载到 body，以动态视口高度限制尺寸；中间区域滚动，关闭、保存、取消按钮保持可见。
- 使用组件 class 而非自定义标签选择器调整富文本编辑器高度。
- 窄屏绑定账户使用原生 select，保留原绑定逻辑；账户列表尚未加载时不丢失已有绑定。
- 加载失败保留旧数据并允许刷新；保存或删除进行中阻止重复提交，删除仍使用 FV 二次确认。

## 回归验证

```sh
cd ui
yarn install --frozen-lockfile
npm test
npm run build
```

`admin-applications-dom.test.mjs` 使用 jsdom 挂载真实 FV 组件，并实际派发按钮事件，
覆盖打开、关闭、必填校验、创建、编辑及单次密钥展示，所有 API 都使用测试替身。
`admin-resumes-mobile.test.mjs` 覆盖移动布局规则、模板编译、加载错误、保存并发、
删除确认、绑定账户回退及移动端选择事件。

这不是浏览器排版或 iPhone 真机视觉验收；线上检查只读 API、页面资源和已有 OIDC 流程，
不创建、重置或删除真实应用，也不保存、删除真实简历。
